# Security Policy

## Scope

EntraHygieneChecker is a **read-only** Microsoft Entra ID hygiene tool. It must never be granted write permissions to Microsoft Graph.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Report privately to the repository owner (Zach Telford / [ztel42](https://github.com/ztel42)) via GitHub Security Advisories or a direct private message. Include steps to reproduce and impact.

We will acknowledge receipt and work on a fix before any public disclosure.
